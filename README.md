
# Parque Estadual Ilha Bela

Esse é um dos primeiros projetos que fiz enquanto estou estudando desenvolvimento web.

A ideia do projeto é criar uma página para um parque fictício, mostrando algumas informações sobre o local e deixando a página com um visual mais agradável.

## Projeto

[Ver o site](https://murilo-dev27.github.io/parque-ilha-bela/)

## Sobre

O projeto começou a partir de uma atividade da DevMedia, onde eu estava praticando HTML.

Depois fui modificando a página e comecei a trabalhar com CSS para melhorar o visual, organizar melhor os elementos e deixar o site adaptado para diferentes telas.

O parque e as informações apresentadas no site são fictícios.

## Tecnologias

- HTML
- CSS

## O que eu pratiquei

Nesse projeto pratiquei principalmente:

- Estruturação de uma página com HTML
- Organização de títulos, textos, imagens e links
- Estilização com CSS
- Cores, fontes e tamanhos
- Espaçamento e alinhamento
- Flexbox e Grid
- Responsividade
- Efeitos ao passar o mouse
- Organização de diferentes seções da página

## Objetivo

Esse projeto faz parte dos meus estudos e foi uma forma de colocar em prática o que estou aprendendo.

Ainda estou no começo dos estudos, então pretendo continuar melhorando esse projeto e criar outros para acompanhar minha evolução.
